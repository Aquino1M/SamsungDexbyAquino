# Aquino Remote — Android

Aplicativo complementar da edição `Aquino1M/SamsungDexbyAquino` para controlar o launcher pelo celular na rede local.

O APK original `AndroidDex.apk` continua sendo o companion de compatibilidade do projeto-base e não tem a autoria reatribuída. O **Aquino Remote** é a camada adicional criada por Aquino1M.

## Controles
- iniciar/focar Android Dex
- abrir Gaming Hub
- abrir Editor de Gamepad
- abrir KeyMapper
- fullscreen
- reparar ADB
- abrir assistente Wi‑Fi/ADB
- diagnóstico
- fechar Android Dex
- status Dex/ADB em tempo real

## Segurança
O bridge usa token local salvo em `config/remote-token.txt`. O celular precisa estar na mesma rede do PC. Porta padrão: `37891`.
