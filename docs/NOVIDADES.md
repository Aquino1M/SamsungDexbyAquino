# Novidades — Android Dex by Aquino V1.3 / 0.4.0 Gaming

- Jogos podem abrir integrados dentro da janela principal do Android Dex.
- Gaming Hub com opção de janela interna ou externa.
- Configurações agora mostram **Jogos, Gamepad e Atualizações**.
- Repositório principal alterado para **Aquino1M/SamsungDexbyAquino**.
- Novo atalho **Configurar Jogos e Gamepad**.
- Editor de mapeamento estilo BlueStacks com pontos visuais sobre a captura do jogo.
- Suporte a teclado, mouse, Xbox/XInput, DualSense via camada SDL/UHID e gamepad-to-touch.
- Detecção de A/B/X/Y, LB/RB, LT/RT, D-pad, Start/Back e movimentos dos dois analógicos.
- Perfis de controle salvos por package Android em `config/keymaps/`.
- Perfis de FPS/baixa latência continuam disponíveis.
- Widget inicial atualizado para **V.1.3 · Aquino1M** com o botão GitHub sem competir com o texto lateral.
